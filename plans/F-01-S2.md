## Goal

Turn a transcript dropped in `inbox/` into a SRC record plus clean, line-numbered text, matched to stakeholders. Then build each agent's input bundle, so agents start from clean data and evals run offline.

S1 is built at the same time. Until it merges, put a local copy of the three S1 signatures in `src/sorter/deps.ts` as an injected `Deps` type (`{ readProject; serializeRecord; allocate }`), and take them as parameters. The CLI wires in the real S1 functions; that wiring is the only part that needs S1 on `f01`.

## Build (all in `packages/records/src/sorter/` and `src/bundles/`)

1. `parse.ts`: `parseTranscript(name, text): Turn[]` where `Turn = { line: number; time?: string; speaker?: string; text: string }`.
   - `.txt` and `.md`: lines like `[00:12:40] Sarah Kim: text` or `Sarah Kim: text`. Lines with no speaker (titles, notes) are kept as turns without a speaker.
   - `.vtt`: cue timing (start time, as `hh:mm:ss`) and `<v Name>` voice tags.
   - Anything else throws `UnsupportedSourceError` (audio and video wait for F-02).
2. `match.ts`: `matchSpeakers(labels: string[], stakeholders): Participant[]`. Case-insensitive exact match on `name`, any of `aliases`, or `email`. No fuzzy matching: no match means no `stakeholder`, and the intake agent holds those claims as pending.
3. `sort.ts`: `sortInbox(dir, inboxPath, deps, opts: { date; runId }): { source: string; files: string[] }`.
   - Size cap 1 MB. `sha256` of the raw bytes; if any existing source's `meta.yaml` has the same `sha256`, throw `DuplicateSourceError` naming that SRC.
   - Allocate one SRC ID. Move the raw file to `records/sources/<SRC>/<original name>` with `fs.renameSync`, leaving the bytes untouched. The workflow's `git add -A` records it as a rename.
   - Write `meta.yaml`: `id`, `type: source`, `title` (first non-empty line, else the file name), `status: draft`, `version: 1`, `created_by: script:intake-sorter`, `source_type: transcript`, `date` (from a `yyyymmdd` or `yyyy-mm-dd` in the file name, else `opts.date`), `participants`, `raw_file`, `sha256`.
   - Write `text.md`: one line per turn, `L<n> [time] Speaker: text`, with `n` matching the turn's line number in the original file.
   - Write the intake input bundle `.factory/runs/<runId>/input.json` (`IntakeInput`; trust `strong` for transcripts).
4. `src/bundles/ba.ts`: `buildBaInput(opts: { project; profile; source; dir? ; url?; token?; fetch? }): Promise<BaInput>`.
   - Offline (`dir`): read the working tree.
   - Online: `POST {url}/api/index/query` with `{ project, type: "claim", confirmation: "confirmed", from_source: source }`, then `{ project, type: "stakeholder" }`.
   - Include only confirmed claims with a `said_by`.
5. `src/sorter/cli.ts`, bundled to `kit/tools/intake-sort.mjs` by the same build script as S1 (add a second entry point next to S1's; if S1 isn't merged yet, add your own `build-kit-tool` entry and note it in your reply). Commands:
   - `sort <inbox_path> --run <id>`: prints the SRC ID on stdout.
   - `bundle ba --source <SRC> --run <id>`: writes `.factory/runs/<id>/input.json`.
   - Online mode uses env `FACTORY_URL`, `INDEX_TOKEN`, `FACTORY_PROJECT`; offline otherwise.
